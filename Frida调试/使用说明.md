# Frida 调试脚本

## 文件说明

- `获取当前界面.js`：通过 Frida 获取当前显示的 Android Activity。
- `显示隐藏进程.js`：拦截 `readdir`，辅助观察被隐藏的 `harrypotter` 进程。

## 使用前

1. 手机开启 USB 调试，并确认电脑能执行 `adb devices`。
2. 安装并确认 Frida 命令可用。
3. 确认游戏包名为 `com.netease.harrypotter`。

## 常用命令

先查看进程：

```powershell
adb shell ps | findstr harrypotter
```

附加到已经运行的进程：

```powershell
frida -U -l 获取当前界面.js -p <进程号>
```

直接启动并注入：

```powershell
frida -U -l 获取当前界面.js -f com.netease.harrypotter
```

运行时请在本目录执行命令，或者给脚本写完整路径。

## 备注

README 中记录的 `items.npk` 是魔杖、猫头鹰等模型资源的位置；本目录的两个脚本本身不负责解包卡牌图片。
