# HPMA 衣柜浏览器 · 演示包

`web` 目录的一份精简拷贝：结构、代码、路径都没改，只是删掉了用不到的模型，并且把**动画整包**、
**完整模型索引**也带了进来。入口还是 `gallery_pc.html`。

## 一、怎么打开

**本地**：双击 `启动.bat`。

它用 Windows 自带的 PowerShell 起一个小服务（`serve.ps1`），端口从 8000 往上找一个空的，然后自动打开
`http://127.0.0.1:端口/gallery_pc.html`。不需要装 Python，也不需要装 Node。关掉命令行窗口就停。

**线上（GitHub Pages）**：
`https://stdquantum.github.io/HPMA/wardrobe-demo/gallery_pc.html`

Pages 的项目站带 `/HPMA/` 前缀，所以页面天生跑在子目录里。原版 `gallery_pc.html` 里肤色图集写的是根路径
`img.src = \`/${path}\``，在子目录下会请求到 `stdquantum.github.io/models_pc/…` → 404 → 脸全黑。
本包已改成 `img.src = \`./${path}\``（只改这一行），本地和 Pages 都对。

## 二、包里有什么

```
gallery_pc.html        查看器（原样，只改了上面那一行肤色路径）
serve.ps1 / 启动.bat   本地服务
说明.md                这份说明
完整清单.json          全量模型索引，5,311 条（只是索引，glb 不在包里）
动画索引.json          全量动画索引，324 条（只是索引，283 段 dev 动画文件不在包里）
brooch_offsets.json    配饰偏移      glasses_offsets.json  眼镜偏移
hat_offsets.json       帽子偏移      hat_mask.json         裁发方案
hide_hat_clothes.json  穿长袍时藏帽子
lib/                   three.js 运行库
anim_pc/               41 段 PC 动画 + index.json（查看器动作栏就靠它）
models_pc/
  manifest_all.json    本包实际用到的清单（69 条，按原 schema）
  body_parts.json      裸皮补片权威表（原样）
  body/ clothes/ hair/ hat/ earring/ glasses/ scarf/ bag/ brooch/
  skin/                8 片 only_* 裸皮
  tones/               31 张肤色图集
```

- 61 件装备/脸：脸 6、衣服 16、发型 13、帽子 9、耳饰 4、眼镜 5、围巾 3、包 3、胸针 2
- 8 片裸皮补片（衣服没做手/腿时补上，不进列表）
- 31 张肤色图集，8 档肤色
- **动作栏 41 段可选**：待机 21 / 走动 7 / 社交 13（都来自 anim_pc，动画文件随包）
- `动画索引.json` 另外记了 324 段（anim_pc 41 + anim_dev 283）的完整信息，`in_pack` 字段标明哪段有动画文件

体积约 84 MB。GitHub Pages 单文件上限 100 MB（本包最大单文件 30 MB，没问题），
站点软上限 1 GB —— 现在只占 8%，很宽松。

## 三、完整清单.json 字段

全量索引，一共 5,311 条（`items` 里键是件号）。拿它对照"游戏里还有哪些没带进来"很方便：

| 字段 | 含义 |
|---|---|
| `item` | 完整件号，如 `female_clothes_100_zmsyxiuzi__high` |
| `category` | body / clothes / hair / hat / earring / glasses / scarf / bag / brooch / skin … |
| `gender` | `girl` / `boy` |
| `lod` | `high` / `low` |
| `file` / `glb` | 文件名、相对路径（`models_pc/<类>/<文件>`） |
| `verts` / `faces` / `bones` | 顶点数 / 面数 / 骨骼数 |
| `skinned` | 是否蒙皮 |
| `texture` / `tex_size` | 贴图名 / 尺寸 |
| `bytes` | 文件体积 |
| `item_short` | 去掉 LOD 后缀的短件号，列表里显示的也是它 |
| `albedo` / `albedo_src` | 原始贴图路径 / 来源 |
| `tones` | 肤色图集数组：`{n, tex, rgb}`，n 是第几档 |
| `skin_rgb` | 没有 8 张图集时用来压色的基准色 |
| `role` | `skin`（裸皮补片）等特殊角色 |

注意：`manifest_all.json`（69 条）才是查看器真正读的清单；`完整清单.json` 只是资料，不参与渲染。
`动画索引.json` 同理，查看器读的是 `anim_pc/index.json`，这份只是"一共有些什么动画"的清单。

## 四、已知

- 男女人形骨架不同（190 / 157 根），跨体型穿会比例失真，页面会给提示
- `anim_dev` 的 283 段动画只给了索引，没带动画文件（要的话从 `web/anim_dev` 拷，约 717 MB）；
  它里面另有 111 个没进索引的片段，索引里本来也没有它们
- 包里只有 61 件装备，列表里不会出现别的衣服
- 模型来自电脑版资源逆向重建，仅供学习研究，别商用
