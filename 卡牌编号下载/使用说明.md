# 卡牌编号下载

## 文件说明

- `下载编号卡牌.py`：按编号请求网易卡牌图片资源，下载成功的图片保存到 `result`。
- `result`：`下载编号卡牌.py` 下载得到的 PNG 图片，图片文件名保持资源编号。
- `下载成功编号.json`：脚本记录的成功下载编号。
- `下载结果比对.ipynb`：另一组编号下载与结果比对实验，涉及 `result` 和可选的 `小程序下载结果` 文件夹。

## 运行 `下载编号卡牌.py`

脚本使用相对路径，先切换到本目录再运行：

```powershell
cd /d "E:\download\HPMA\卡牌编号下载"
python 下载编号卡牌.py
```

脚本会把图片写入当前目录下的 `result`，并更新当前目录下的 `下载成功编号.json`。网络不可用或资源不存在时，对应编号不会保存。

## 注意

- 图片及其编号文件名没有改动。
- 如果以后从其他目录启动脚本，相对路径可能失效；建议始终在本目录运行。
