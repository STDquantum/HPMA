# 卡牌网页整理

## 文件说明

- `获取并整理卡牌.ipynb`：使用 Playwright 获取并解析藏宝阁账号卡牌内容。
- `background`：Notebook 下载的卡牌图、卡牌框、魔力数字等资源。
- `卡牌信息.json`：Notebook 生成的卡牌信息。
- `卡牌合成.html`：使用本地素材生成的仿网页卡牌页面。

## 使用步骤

在本目录打开并运行 `获取并整理卡牌.ipynb`：

```powershell
cd /d "E:\download\HPMA\卡牌网页整理"
jupyter notebook 获取并整理卡牌.ipynb
```

建议按 Notebook 单元格顺序执行：先用 Playwright 获取网页内容，再解析卡牌、保存 `卡牌信息.json`、下载 `background` 素材，最后生成 `卡牌合成.html`。

## 注意

资源地址来自网页中记录的网易资源服务器地址；如果网页内容或资源地址发生变化，解析结果可能需要调整。
