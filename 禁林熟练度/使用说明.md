# 禁林熟练度自动化

## 文件说明

- `禁林熟练度自动化.py`：使用 ADB 截图、OpenCV 模板匹配和点击操作，循环执行熟练度流程。
- `button_star8.png`、`button_start.png`、`button_confirm.png`：按钮模板图。
- `screenshot.png`：脚本运行时保存的手机截图，会被覆盖。

## 依赖

```powershell
pip install opencv-python numpy requests
```

并确认 `adb devices` 能看到目标手机。

## 使用步骤

1. 打开手机 USB 调试，并连接设备。
2. 用 `adb devices` 确认设备在线。
3. 打开游戏并进入对应的禁林熟练度界面。
4. 检查 `禁林熟练度自动化.py` 中的设备序列号是否与自己的设备一致；当前脚本写死了一个设备号，需要时自行替换。
5. 在本目录执行：

```powershell
python 禁林熟练度自动化.py
```

脚本依赖当前工作目录中的按钮图片，因此不要从其他目录直接运行；或者先切换到本目录。

## 注意事项

- 屏幕分辨率、界面布局或按钮样式变化后，模板匹配可能失败，需要重新截取按钮模板。
- 脚本会持续循环并模拟点击，请先确认游戏处于正确界面。
- 原脚本内含钉钉机器人 Webhook 配置。若该地址仍有效，建议更换或撤销，避免凭据泄露。
