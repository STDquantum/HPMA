# 舞会与安卓自动化

## 内容概览

本目录包含一套基于视频标注和 ADB 输入的自动化实验文件：

- `视频标注.py`：从 `舞会标注视频.mp4` 交互标注点击、按住和滑动操作。
- `日志生成滑动标注.py`：从 `滑动标注日志.txt` 整理滑动标注。
- `合并点击滑动标注.py`：合并点击和滑动标注。
- `坐标转换.py`、`滑动转点击.py`：坐标转换和点击操作展开。
- `合并同帧滑动.py`、`拆分滑动标注.py`：合并或拆分滑动操作。
- `ADB回放标注.py`：读取最终标注 JSON，通过 ADB 按时间回放操作。
- `底层触摸回放.py`：通过 `sendevent` 发送底层触摸事件，需要设备权限和正确的输入设备号。
- `视频预处理.py`、`舞会原始视频.mp4`、`舞会标注视频.mp4`：视频处理和相关素材。
- `annotation_*.json`、`检测操作.json`、`生成的ADB脚本.sh`：中间数据和生成的 ADB 操作脚本。

## 基本运行原则

这些脚本使用相对路径，必须在本目录执行。例如：

```powershell
cd /d "E:\download\HPMA\舞会与安卓自动化"
python 视频标注.py
```

具体脚本的输入文件名写在脚本开头。建议按照“视频标注 → JSON 整理/转换 → `ADB回放标注.py` 回放”的顺序使用。

## 回放前检查

1. 手机开启 USB 调试，并确认 `adb devices` 能识别设备。
2. 检查 `ADB回放标注.py` 中的分辨率、帧率、初始点击坐标和时间偏移。
3. 确认 `annotation_all_transformed_split_sorted.json` 已生成。
4. 先在非关键场景小范围测试，再运行完整回放。

## 风险提示

ADB 自动化会真实点击手机；`底层触摸回放.py` 还可能需要 root 权限。设备分辨率、帧率或界面变化时，坐标和时间参数需要重新校准。
